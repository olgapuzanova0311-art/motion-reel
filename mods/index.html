5 модов для Claude Code

Мод это маленькая программа внутри Claude Code, которая меняет его внешний вид и добавляет новые умения. Ниже ссылки на все пять из ролика и команды, чтобы их поставить.

МОД 1

Token Weather

Прогноз погоды для контекста над полем ввода. Солнце, когда места много, ливень, когда занято больше половины, гроза, когда контекст скоро сожмётся. Официальный пример от Anthropic.

git clone https://github.com/anthropics/claude-code-playground.git
cd claude-code-playground/claude-code/mods
claude --plugin-dir ./token-weather

Так мод включится на одну сессию. Нужна версия Claude Code 2.1.287 или новее.

github.com/anthropics/claude-code-playground/tree/main/claude-code/mods
МОД 2

cctop

Следит за сессиями: токены, кэш, контекст, лимиты и сколько стоит работа. Запускается в соседнем окне терминала, как диспетчер задач для Claude Code.

brew install stefanprodan/tap/cctop
cctop

Без Homebrew: curl -fsSL https://raw.githubusercontent.com/stefanprodan/cctop/main/install.sh | sh

github.com/stefanprodan/cctop
МОД 3

Prismantis

Делает ответы наглядными: таблицы, графики, диаграммы и подсветка кода в 15 темах, с кнопками копирования.

/plugin marketplace add NahumLitvin/prismantis
/plugin install prismantis@prismantis
/prismantis setup

Последняя команда открывает выбор темы. Выключить мод можно через /plugin.

github.com/NahumLitvin/prismantis
МОД 4

Flow

Живое дерево сабагентов рядом с перепиской: кто чем занят, сколько было вызовов и кто завис.

claude plugin marketplace add Charlie0113-T/claude-agent-flow
claude plugin install agent-flow@claude-agent-flow

Потом в Claude Code набери /flow и попроси Claude запустить сабагентов.

github.com/Charlie0113-T/claude-agent-flow
МОД 5

Doom

Запускает Doom прямо в панели Claude Code, чтобы было чем заняться, пока Claude работает.

/plugin install intermission --marketplace jarrodwatts/intermission
/intermission

Работает на macOS 15 в терминалах Ghostty или kitty, на Windows в Rio. При первом запуске скачает игру, около 20 МБ. Выключить: /intermission off

github.com/jarrodwatts/intermission

Как поставить любой мод

  • В приложении нажми плюс у поля ввода, выбери Plugins и Add Plugin.
  • В терминале набери /plugin.
  • Если мод лежит на GitHub, сначала добавь репозиторий, потом установи мод:
/plugin marketplace add автор/репозиторий
/plugin install название@репозиторий

Свой мод за одну просьбу

Попроси Claude, например:

Сделай мод, который показывает над полем ввода, сколько токенов в кэше

Такой мод живёт только в текущей сессии. Чтобы он остался, сохрани его папку и запускай Claude с флагом:

claude --plugin-dir ./папка-мода

Про безопасность

Мод работает с твоими правами и без песочницы. Ставь моды только от тех, кому доверяешь, и перед установкой загляни в код репозитория.
