# motion-reel

Лендинг-лид-магнит и навык для Claude Code: кинематографичный моушн-ролик с озвучкой одним промптом (Remotion).

- `index.html`: форма (телефон + ник в Telegram), заявка уходит на приёмник в Railway (`motion-leads`) и пересылается в Telegram.
- `guide.html`: инструкция и ссылка на скачивание навыка.
- `skill/motion-reel/`: исходники навыка (SKILL.md + шаблон Remotion).
- `download/motion-reel.zip`: архив навыка для скачивания. Пересобрать: `cd skill && zip -qr ../download/motion-reel.zip motion-reel -x '*.DS_Store'`.
