# Моушн-ролик одним промптом

Ты собираешь ролик 16:9 (1920×1080, 30 fps) из готового шаблона: каждая фраза озвучки = своя сцена с анимацией. Готовый пример (ролик «Это пипец, смотрите, что я натворила») уже лежит в шаблоне: его можно отрендерить как есть или переписать под свою тему.

Всё делай сам, пользователя спрашивай только о том, что меняет суть (тема, чей голос). Пиши пользователю по-русски, коротко и по делу.

## Шаг 0. Проверь окружение
- **Node.js 18+**: `node -v`. Нет: поставь с nodejs.org (LTS) или `brew install node`.
- **ffmpeg**: `ffmpeg -version`. Нет: `brew install ffmpeg` (macOS) / `winget install ffmpeg` (Windows) / `sudo apt install ffmpeg`.
- **uv** (нужен только для синтеза голоса): `uv --version`. Нет: `curl -LsSf https://astral.sh/uv/install.sh | sh` (Windows: `powershell -c "irm https://astral.sh/uv/install.ps1 | iex"`).

## Шаг 1. Создай проект
Скопируй папку `template/` из этого навыка в рабочую папку пользователя (по умолчанию `~/motion-reel`) и поставь зависимости:
```bash
cp -R "<папка навыка>/template" ~/motion-reel && cd ~/motion-reel && npm install
```

## Шаг 2. Сценарий
Текст лежит в `public/reel/lines.src.json`: `[["id", "фраза"], ...]`, одна фраза = одна сцена.
- Если пользователь не дал тему: оставь готовый сценарий из шаблона.
- Если дал тему: перепиши фразы: коротко, разговорно, с эмоцией, 20–35 фраз на 40–60 секунд. Первая фраза: хук, последняя: призыв («Напиши в комментах слово …»).
- **Ударения**: ставь апостроф ПОСЛЕ ударной гласной во всех словах из 2+ слогов: `ка'мера`, `шабло'н`, `ре'ндер`. Без этого синтез путает ударения. Англ. названия пиши кириллицей: «Клод Код», «А'фтер Эффе'ктс».

## Шаг 3. Сцены
- `src/reel/Reel.tsx` → массив `SCENES`: какая сцена, какие фразы в ней звучат (`voices` = id из lines), паузы `pre`/`tail`/`gap`, минимальная длина `min` (секунды). `SPEED` сжимает все паузы (1.3 = на 30% динамичнее).
- `src/reel/scenes.tsx`: готовые сцены. Каждая получает `d` (длина в кадрах), `v` и `ve` (кадры начала/конца каждой фразы), чтобы анимация попадала в слова.
- `src/reel/kit.tsx`: детали: фоны `BgDark` / `BgLight` / `BgRed`, `Rays` (лучи), `Letters` (буквы влетают по очереди: `from="up" | "blur" | "scale"`), `Pop` (блок влетает с размытием), `H` (заголовок), `Burst` (колючая звезда), `ClaudeMark`, функции `p()` (прогресс 0→1) и `lerp()`.

## Шаг 4. Голос
**А. Синтез (по умолчанию, бесплатно):**
```bash
uvx --with edge-tts python scripts/tts.py          # все фразы
uvx --with edge-tts python scripts/tts.py okey     # перегенерировать одну
```
Голос: `VOICE=ru-RU-SvetlanaNeural` (женский) или `ru-RU-DmitryNeural` (мужской), темп `RATE=+25%`. Скрипт сам обрезает тишину и пишет длительности в `src/reel/durations.json`. При синтезе поставь в Reel.tsx `SPEED = 1` (темп регулирует `RATE`).

**Б. Свой голос (звучит живее всего):** пользователь читает все фразы подряд одним файлом.
1. Положи файл в `public/reel/my_voice.wav` (`ffmpeg -i запись.mp3 -ac 1 -ar 48000 public/reel/my_voice.wav`).
2. `node scripts/transcribe.mjs public/reel/my_voice.wav`: слова с таймингами; паузы: `ffmpeg -i public/reel/my_voice.wav -af silencedetect=noise=-38dB:d=0.12 -f null -`.
3. Составь `public/reel/cuts.json` (формат: в шапке `scripts/cut_voice.py`): режь в паузах, где паузы нет: ровно перед первым словом следующей фразы.
4. `python3 scripts/cut_voice.py public/reel/cuts.json`. Если в cuts.json `speed: 1.3`: поставь и в Reel.tsx `SPEED = 1.3`.
5. Проверь стыки: склей нарезанные фразы и прогони через transcribe.mjs: все слова должны быть целыми.

## Шаг 5. Проверка до рендера
- Кадр: `npx remotion still src/index.ts reel out/check.png --frame=120 --scale=0.5` и посмотри картинку.
- Превью в браузере: `npm run studio`.

## Шаг 6. Рендер
```bash
npm run render
ffmpeg -y -i out/reel.mp4 -c:v copy -af "loudnorm=I=-14:TP=-1.5:LRA=11" -c:a aac -b:a 192k out/reel_final.mp4
```
Посмотри раскадровку готового ролика (`ffmpeg -i out/reel_final.mp4 -vf "fps=1,scale=320:-2,tile=8x8" -frames:v 1 out/sheet.jpg`) и проверь, что тексты не обрезаны и сцены идут по порядку. Отдай пользователю путь к `out/reel_final.mp4`.

## Как из этого сделать рилс
Включи ролик на ноутбуке во весь экран и сними экран на телефон вертикально: как в оригинальном рилсе. Или сделай вертикальную версию: в `src/Root.tsx` 1080×1920 и перестрой вёрстку сцен под узкий кадр.
