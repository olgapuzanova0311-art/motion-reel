Как запустить

1

Поставь Claude Code

Нужна подписка Claude Pro или выше. Скачай приложение Claude для компьютера и открой вкладку Code, или поставь Claude Code в терминал.

Скачать Claude Claude Code в терминале
2

Скачай навык

Нажми кнопку выше. Файл motion-reel.zip окажется в папке «Загрузки». Распаковывать его вручную не нужно.

3

Подключи навык

Самый простой способ: открой Claude Code и отправь ему это сообщение. Он сам распакует навык куда нужно.

Установи навык из архива motion-reel.zip в папке «Загрузки»: распакуй его в ~/.claude/skills/ так, чтобы получилось ~/.claude/skills/motion-reel/SKILL.md

Или вручную, командой в терминале:

mkdir -p ~/.claude/skills && unzip -o ~/Downloads/motion-reel.zip -d ~/.claude/skills/
Expand-Archive -Force "$env:USERPROFILE\Downloads\motion-reel.zip" "$env:USERPROFILE\.claude\skills"

Важно: после установки начни в Claude Code новый чат, чтобы он увидел навык.

4

Вставь промпт и жми Enter

Используй навык motion-reel. Сделай 15-секундную кинематографичную анимацию: кинетическая типографика, морфинг форм, 3D, плавная камера. Возьми готовый сценарий из шаблона, озвучь его и отрендери видео. Всё нужное для работы установи сам.

Замени то, что в квадратных скобках, на своё.

Используй навык motion-reel. Я записал(а) голос: [ПУТЬ К ФАЙЛУ, например ~/Downloads/voice.mp3]. Нарежь запись по фразам под сцены, ускорь в 1,3 раза и отрендери ролик с моим голосом.

Сначала попроси Claude показать текст сценария, прочитай его вслух одним файлом (голосовое с телефона подойдёт) и отправь путь к файлу. Живой голос звучит лучше любого синтеза.

5

Забирай видео

Claude сам поставит всё нужное, соберёт сцены, озвучит и отрендерит ролик. В конце он пришлёт путь к готовому файлу reel_final.mp4.

Как снять рилс, как у меня: включи ролик на ноутбуке во весь экран и сними экран на телефон вертикально. Хочешь, чтобы что-то было иначе? Просто напиши Claude: «сделай быстрее», «поменяй цвет на синий», «убери эту фразу».

Вопросы

Нужно ли уметь программировать?

Нет. Код пишет и запускает Claude, ты только вставляешь промпт и говоришь, что поменять.

Сколько это стоит?

Навык бесплатный. Нужна подписка Claude Pro. Озвучка синтезом бесплатная, программы для рендера тоже.

Подойдёт Windows?

Да, работает на Mac и Windows. Нужен компьютер, на телефоне не получится.

Голос ставит неправильные ударения

Попроси Claude: «поставь ударения апострофом во всех словах и переозвучь». Или запиши текст своим голосом, это звучит живее всего.

Что-то не устанавливается

Скопируй ошибку и отправь её Claude со словами «почини». Обычно он сам ставит недостающее: Node.js, ffmpeg или uv.
